# Python Automation & Web Applications

## Overview

Supporting projects showing experimentation beyond conventional analytics notebooks, including web data collection and a small Flask application.

## Web Scraping & Data Collection

The retained Python scraping work uses HTTP requests and BeautifulSoup-style parsing to collect information from web pages, clean extracted values, add timestamps, and persist collected records to CSV. This demonstrates the mechanics of turning an external web source into structured data for subsequent analysis.

### Skills demonstrated

- HTTP requests
- HTML parsing
- Data extraction and cleaning
- Timestamping
- CSV persistence
- Repeatable collection logic

## Flask Application

The retained Flask server demonstrates:

- Application initialization
- URL routing
- Template rendering
- Dynamic page routing
- GET/POST form handling
- Form conversion to structured data
- CSV persistence
- Redirect-based confirmation flow

This is not presented as a production web application. Its value in the portfolio is evidence of early experience connecting Python logic to a user-facing application workflow.

## Portfolio Role

**Supporting technical evidence.** These projects broaden the portfolio beyond modeling by showing exposure to data acquisition and application delivery. More recent portfolio work uses Streamlit and more structured analytical application patterns.

## Limitations

The original examples are intentionally described conservatively. They do not imply production deployment, hardened security, scalable storage, API engineering, or enterprise web-development experience.
