# Movie Revenue Analytics

## Overview

An earlier Python data-analysis project using movie data to explore relationships associated with gross revenue. The project provides a compact example of the standard analytical workflow: load data, inspect quality, clean and transform fields, explore distributions and relationships, and use correlation-oriented analysis and visualization to investigate candidate drivers.

## Tools

- Python
- pandas
- NumPy
- Matplotlib / analytical visualization
- Exploratory data analysis
- Correlation analysis

## Analytical Workflow

1. Load and inspect the movie dataset.
2. Evaluate missingness and data types.
3. Clean fields needed for analysis.
4. Explore distributions and relationships among candidate variables.
5. Calculate and inspect correlations.
6. Visualize relationships associated with movie gross revenue.

## What This Demonstrates

- Data-quality inspection before analysis
- DataFrame manipulation
- Exploratory analysis
- Translating a broad question into measurable relationships
- Correlation-based feature investigation
- Analytical visualization

## Interpretation & Limitations

Correlation is used here as an exploratory measure of association, not evidence of causation. Movie revenue can be influenced by many observed and unobserved factors, and the project should be viewed as an exploratory Python analysis rather than a causal or production forecasting model.

## Portfolio Role

This project is intentionally retained as a standalone example because it provides a clear, accessible Python analytics story distinct from the optimization, machine-learning, and application-development work elsewhere in this repository.
