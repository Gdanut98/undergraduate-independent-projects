## How to Read This Repository

The work here predates or sits between my undergraduate and graduate portfolio projects. Some source files began as coursework or structured learning exercises; others were independent practice or personal projects. Where provenance is clear, it is identified in the relevant project documentation. I do not represent learning exercises as production systems or employer work.

The repository is intentionally curated. Large raw datasets, virtual environments, notebook checkpoints, IDE metadata, history files, database dumps, and redundant introductory exercises are excluded when they do not add useful technical evidence.

## Evidence Standard

Each project area is documented around the same questions:

- What analytical or technical problem was being practiced or solved?
- Which tools and methods are demonstrated by the source work?
- What implementation evidence is available?
- What results or outputs can be supported by the surviving files?
- What limitations should a reviewer understand?
- Which elements are original source work versus later portfolio documentation or refactoring?

## Publication Notes

Only publication-safe material is included. Raw source datasets are not automatically redistributed simply because they were used in an analysis. Employer data, proprietary materials, credentials, secrets, personal identifiers, and unnecessary environment files are excluded.
