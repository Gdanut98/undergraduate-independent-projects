# Excel Simulation & Decision Modeling

## Overview

This collection represents spreadsheet-based analytical work across simulation, probability, optimization, modeling, PivotTables/Power Pivot, visualization, and advanced Excel techniques.

## Methods Demonstrated

- Monte Carlo simulation
- Discrete probability modeling
- Random-number-driven scenarios
- Spreadsheet optimization
- Advanced formulas and analytical functions
- PivotTables and Power Pivot
- Data visualization and dashboard-oriented spreadsheet work
- Scenario and decision modeling

## Representative Project: Car Insurance Monte Carlo Simulation

The retained workbook contains a simulation sheet with approximately one thousand simulated records and models claim-count probabilities together with claim-cost assumptions. It provides direct evidence of using Excel as a stochastic decision-modeling environment rather than only for reporting or tabulation.

## What This Demonstrates

- Translating probability assumptions into spreadsheet logic
- Repeated stochastic simulation
- Structuring assumptions separately from simulated outcomes
- Using spreadsheets for decision analysis
- Building a foundation for later Monte Carlo and quantitative-risk work

## Portfolio Interpretation

Excel remains an important analytical tool in business environments, but these earlier projects are presented as technical foundations. More recent portfolio work extends simulation and optimization concepts into Python, Gurobi, statistical modeling, and graduate quantitative-risk applications.
